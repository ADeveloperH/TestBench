# 日志存储与清理

更新：2026-11-20。此功能仅管理本机TestBench原始logcat会话，不改变日志筛选、测试用例、手机数据、自动化方案或视频交付规则。

发布版本：TestBench v1.0.9。更新说明维护于`config/release-notes.txt`，推送`v1.0.9`标签触发现有的Windows、macOS自动构建及更新清单发布。

## 配置与入口

“设置 → 通用 → 日志存储”展示日志总占用、历史会话数、受保护会话占用，提供自动清理开关、保留天数、容量目标、保存、按规则清理、清空历史日志和打开日志目录。默认自动清理开启、保留7天、容量目标1 GB（十进制）。配置由Rust持久化到应用数据目录log-storage.json，前端不另存一份；普通配置导入/恢复不重置本机日志策略。

已有历史数据首次启用规则前必须预览并确认，未确认不自动删除。首次没有日志时可直接采用默认规则；保存启用策略时预览影响并确认，取消不修改策略或日志。自动清理关闭时仍可手动预览清理。

## 清理规则

原始日志保存在应用数据目录sessions/<纳秒时间>/logs-NNNN.log，每段约50 MiB。按会话最后写入时间判断过期；先清理超过保留期的历史会话，再按最旧优先清理到容量目标。每次删除整个历史会话，不截断当前日志。

容量是清理目标而非强制截断上限。采集或导出保护的数据超过目标时提示仍超额，不关闭采集、不丢日志。停止采集仍保留当前会话直到新会话替换或应用退出。操作系统文件锁保护各实例会话与导出；清理重检占用和预览快照，已变化、无法确认或未知格式的目录不删除。只处理本工具生成的会话与日志文件，不跟随软链接，不递归删除未知内容。

跨实例保护要求实例使用支持会话租约的新版；旧版未持有操作系统锁，首次清理前需先退出旧版TestBench，确认提示会明确提醒。配置损坏或无法读取时停止清理并显示错误，不回退默认规则后删除历史。

手动“按规则清理”和“清空历史日志”都先显示会话数量、预计释放空间和保护情况，再确认。确认仅作用于该预览中的候选会话；新会话和预览后变化的会话跳过，过期预览需重新生成。清理异常按会话记录，不中断日志采集。

## 生命周期与性能

应用启动、新建采集会话、保存策略后及每10分钟触发后台清理；统计、扫描、删除和完整日志复制不在UI线程执行，自动任务不并发堆积。清理失败只记录并显示结果。完整会话导出先刷新并固定文件长度、持有会话保护，再释放采集互斥锁后台复制；导出期间采集可继续。

操作完成后强制刷新统计，较早的后台统计响应不得覆盖新结果。确认弹框在矮窗口中支持滚动，取消或Esc不执行清理。

日志页“清空”仍只清理显示与设备logcat缓冲，不删除磁盘历史；完整会话导出包含该会话所有已落盘日志，不受前端显示窗口限制。自动化方案、偏好设置和用户另存的导出文件不在清理范围。

## 验证要求

使用临时目录回归默认值、首次确认、策略持久化、过期与容量顺序、停止后保护、跨进程锁、导出保护、预览变化/过期、软链接和未知文件、部分失败及配置损坏保护。测试不得清理真实sessions目录。前端检查深浅主题、窄窗口、Select与确认/取消行为；明确区分纯逻辑、浏览器和真实Tauri/设备验收。
