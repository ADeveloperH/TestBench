# TestBench 用户使用手册

> 本文档面向**使用者/测试人员**，说明如何安装、使用与更新 TestBench。
> 开发与维护相关内容见项目根目录 [README.md](../README.md)。

## 简介

TestBench 是一站式 Android 设备调试工作台：连接手机后即可实时查看日志、按条件过滤、管理设备、安装 APK、投屏录屏、跑日志回归测试、监控性能。Windows 与 macOS 均可使用，无需自行安装 adb / scrcpy。

## 一、安装

### 下载

从 GitHub Releases 下载对应安装包：

- **macOS（Apple Silicon / M 系列）**：`TestBench_x.y.z_aarch64.dmg`
- **macOS（Intel）**：`TestBench_x.y.z_x64.dmg`
- **Windows**：`TestBench_x.y.z_x64-setup.exe` 或 `TestBench_x.y.z_x64_en-US.msi`

### macOS 安装与首次信任

1. 打开 `.dmg`，把 **TestBench** 拖入「应用程序」
2. **必须从 /Applications 启动**（自动更新依赖该位置，不要在 dmg 内直接运行）
3. 双击打开时若提示「已损坏 / 无法验证开发者」，二选一放行（**每台机器首次执行一次**即可）：

   - **方式 A（推荐）**：系统设置 → 隐私与安全性 → 在底部找到「TestBench」→ 点「仍要打开」
   - **方式 B**：右键 TestBench 图标 → 打开 → 再点「打开」
   - **方式 C（脚本）**：运行本目录下的 `放行TestBench.command`（右键 → 打开）

> 说明：当前安装包为 ad-hoc 签名（未公证），所以首次有安全提示。放行后所有后续版本由 App 内自动更新，无需再次手动放行。

### Windows 安装

1. 双击 `.exe` 或 `.msi` 安装包，按向导完成
2. 若弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」
3. 首次运行弹防火墙授权时请点「允许访问（专用网络）」，否则无线配对可能失败

## 二、自动更新

- App 启动约 4 秒后**自动后台检查更新**；也可在设置页点「检查更新」手动触发
- 发现新版本会弹窗显示版本号与更新说明，点「立即更新」→ 下载（带进度）→ 安装 → 自动重启，全程无需手动下载
- 更新失败（如网络问题、签名校验不通过）会提示，原版本继续正常使用，稍后重试即可
- 更新包经签名校验，签名不符会拒绝安装，保证安全

## 三、使用说明

### 连接设备

- **USB**：手机开启「开发者选项 → USB 调试」，插线后在工具内点「刷新设备」选择
- **无线（Android 11+）**：手机「开发者选项 → 无线调试」，工具设置页点 WiFi 图标 → 两种方式任选：
  - **配对码**：手机点「使用配对码配对设备」给出地址与 6 位码，填入工具点「配对」
  - **二维码**：工具点「生成二维码配对」，手机「无线调试 → 扫码配对」扫工具二维码
  - 配对成功后工具自动用 mDNS 发现连接地址；若未自动发现，把手机「无线调试」页顶部的「IP 地址和端口」填入「连接地址」点「连接」

### 日志查看

- 选中设备后自动开始抓取日志，实时滚动显示
- **过滤**：按级别（V/D/I/W/E/F/A）、关键字搜索（支持正则，点 `.*` 切换）、Tag（逗号分隔，支持 `!` 排除）、应用（按包名解析 PID）
- **已保存过滤器**：设好条件后点「保存筛选」，下拉一键切换
- **常用搜索/Tag**：输入框点历史可收藏常用项，悬停看描述
- 操作：空格暂停、`Cmd/Ctrl+L` 清空、`Cmd/Ctrl+E` 导出；长日志双击展开/收起

### 工具页

应用后门、重启、清数据、卸载、截图、安装 APK（可拖拽）、投屏、录屏、设备信息、当前 Activity、Alarm、性能监控等，按需使用；危险操作（清数据/卸载）有确认提示。

### 测试用例（回归测试）

设置页「测试用例」标签管理规则（AND/OR 条件树、出现 N 次、缺失判定）；日志页右侧侧边栏实时显示各用例通过/问题状态，点击可定位到对应日志。

### 设置

- **应用/搜索/Tag/过滤器/测试用例**：管理各 tab 内容（内置条目不可删除，自己添加的可删改）
- **导出/导入配置**：把本机配置打包分享给同事，导入按「本地优先」合并
- **导出调试日志**：遇到问题点时导出诊断报告发给维护者
- **刷新配置**：手动拉取最新的内置配置

### 快捷键

| 操作 | 快捷键 |
|---|---|
| 暂停 / 继续抓取 | 空格 |
| 打开日志查找 | Cmd/Ctrl + F |
| 查找：下一个匹配 | Enter / ↓ |
| 查找：上一个匹配 | Shift + Enter / ↑ |
| 关闭查找 | Esc |
| 复制所选日志 | Cmd/Ctrl + C |
| 清空日志 | Cmd/Ctrl + L |
| 导出日志 | Cmd/Ctrl + E |
| 展开 / 收起长日志 | 双击日志行 |

> 日志页按 `Cmd/Ctrl + F` 打开查找条：高亮所有匹配、显示匹配计数，支持正则与大小写切换。

## 四、常见问题

- **工具里没有设备**：点「刷新设备」；无线连接参考上文「连接设备」；确保手机与电脑同一局域网（或手机开热点）
- **投屏后系统界面能点、游戏内点击无效**：OPPO/小米等 ROM 需开启开发者选项里的「**USB调试（安全设置）**」。快速判定：开发者选项打开「指针位置」，执行 `adb shell input tap <x> <y>`——屏幕出现白色轨迹但应用不响应即为该开关未开启。部分 OPPO 机型开启该开关需插 SIM 卡并登录 OPPO 账号验证
- **Windows 首次运行防火墙拦截**：点「允许访问（专用网络）」，否则二维码配对和自动连接失败
- **Windows 杀毒软件报毒（adb.exe 误报）**：对安装目录（默认 `C:\Program Files\TestBench`）添加信任/白名单
- **更新失败 / 无法连接更新服务器**：检查网络；稍后点「检查更新」重试；不影响当前版本使用
- **其他问题**：设置页点「导出调试日志」，把生成的报告发给维护者
