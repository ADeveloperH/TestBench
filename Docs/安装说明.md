# TestBench 安装说明（内部测试版）

当前安装包**未签名**（正式签名在规划中），安装时会有系统安全提示，按下面对应平台操作即可。

## Windows

1. 下载 `.msi` 或 `.exe` 安装包，双击运行；
2. 若弹出「Windows 已保护你的电脑」蓝色提示：
   - 点击「**更多信息**」；
   - 点击「**仍要运行**」；
3. 按安装向导完成即可。

## macOS

1. 下载 `.dmg`，打开后把 **TestBench** 拖入「应用程序」；
2. 双击打开若提示「**已损坏，无法打开**」或「无法验证开发者」，按顺序放行：

   **第 1 步**：打开「终端」粘贴执行（清除下载隔离属性）：

   ```bash
   xattr -cr /Applications/TestBench.app
   ```

   **第 2 步**：若仍提示「已损坏」，执行本机重新签名：
   1. 先安装 Xcode 命令行工具（如已安装可跳过）：终端执行 `xcode-select --install`；
   2. 终端执行：

   ```bash
   codesign --force --deep -s - /Applications/TestBench.app
   ```

3. 然后**右键** TestBench 图标 → 「打开」→ 确认打开；
   或：系统设置 → 隐私与安全性 → 找到提示 → 点「仍要打开」。

> 说明：当前安装包未做开发者签名（正式签名在规划中），以上是未签名应用的标准放行方式，**每台机器首次安装执行一次**即可。
>
> **Intel 芯片的 mac**：请下载 `testbench-macos-x64` 包；`testbench-macos-arm64` 仅适用于 Apple Silicon（M 系列）。

## 使用前提

- 电脑与手机在**同一局域网**，或手机开热点给电脑连；
- 手机开启：开发者选项 → 无线调试（或 USB 调试后插线）；
- 首次连接设备需在手机确认「允许 USB 调试」。

## 常见问题

- **软件里没有设备**：点「刷新设备」；WiFi 连接参考设置页「帮助」里的配对说明；
- **Windows 首次运行弹防火墙授权**：请点「允许访问」（专用网络），否则二维码配对和自动连接会因 mDNS 被拦截而失效；手动填配对码和连接地址不受影响；
- **Windows 杀毒软件报毒（adb.exe 误报）**：adb 是被恶意软件滥用的常用工具，部分杀毒软件会误报。请在杀毒软件里对安装目录（默认 `C:\Program Files\TestBench`）添加信任/白名单；正式签名后可大幅减少误报；
- **遇到问题**：设置页右上角「导出调试日志」，把生成的报告发给维护者。
