# TestBench 安装说明（内部测试版）

当前安装包**未签名**（正式签名在规划中），安装时会有系统安全提示，按下面对应平台操作即可。

## Windows

1. 下载 `.msi` 或 `.exe` 安装包，双击运行；
2. 若弹出「Windows 已保护你的电脑」蓝色提示：
   - 点击「**更多信息**」；
   - 点击「**仍要运行**」；
3. 按安装向导完成即可。

## macOS

1. 下载 `.dmg`，打开后把 **TestBench** 拖入「应用程序」；
2. 首次打开会提示「无法验证开发者」，先按下面方式放行：

   **方式一（推荐，最常用）**：打开「终端」粘贴执行：

   ```bash
   xattr -cr /Applications/TestBench.app
   ```

   **方式二**（方式一无效时）：
   1. 安装 Xcode 命令行工具：终端执行 `xcode-select --install` 并按提示完成；
   2. 终端执行：

   ```bash
   codesign --force --deep -s - /Applications/TestBench.app
   ```

3. 然后**右键** TestBench 图标 → 「打开」→ 确认打开；
   或：系统设置 → 隐私与安全性 → 找到提示 → 点「仍要打开」。

## 使用前提

- 电脑与手机在**同一局域网**，或手机开热点给电脑连；
- 手机开启：开发者选项 → 无线调试（或 USB 调试后插线）；
- 首次连接设备需在手机确认「允许 USB 调试」。

## 常见问题

- **软件里没有设备**：点「刷新设备」；WiFi 连接参考设置页「帮助」里的配对说明；
- **遇到问题**：设置页右上角「导出调试日志」，把生成的报告发给维护者。
