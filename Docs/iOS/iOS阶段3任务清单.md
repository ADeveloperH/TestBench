# iOS 阶段 3：正式日志工作区接入

更新时间：2026-11-12

## 目标与优先级

优先把已验证的 iOS 采集能力接入现有正式日志工作区，复用设备选择、采集控制、列表、搜索、详情、导出和测试用例侧栏。Probe 按用户意见保留为 iOS 内部后门／诊断入口，共享唯一采集会话，不新增网络服务或绕过权限；保留现有内部构建入口开关。

阶段编号表示功能归属，不要求阶段 2 全部完成后才能开始阶段 3。现有设备发现、启停、事件和独立落盘已具备接入基础；正式接入开发先于 IOS2-300～330 打包任务。跨平台和稳定性验收是发布门槛。
