# iOS 正式日志面板 UI 对齐计划

日期：2026-11-12；关联：IOS3-060 补齐、IOS3-061～065。状态：061～064 已实现；063/064 完成 macOS iOS 部分自测，保留待验收，最终一致性待 065。

## 目标与优先级

正式日志页在切换 Android/iOS 后，保持相同的工作区骨架、操作位置、列表交互和详情体验，通过列定义、筛选项及能力控制表达平台差异。优先于下一轮完整工作区与跨平台验收实施。

Probe 保留为 iOS 内部后门／诊断入口，用于设备通信、配对、工具路径、采集指标和异常排查。这里的“后门”指应用内诊断工具，不新增网络服务、权限绕过或第二套采集后台。保留当前开发模式/内部验收构建入口开关，不因本轮 UI 对齐默认向普通生产包开放。

## 原始源码核对与缺口（2026-11-10）

| 范围 | 当前 Android | 当前正式 iOS | 对齐要求 |
|---|---|---|---|
| App 组装 | `src/App.tsx` 的 `log-main/log-left` + `LogList` | 同文件独立分支直接挂载 `IosLogList` | 共用布局骨架，App 只组装，不继续堆平台 UI 分支 |
| 筛选和动作 | 正式工具栏、HistoryInput、正则、保存过滤器，通用动作入口 | 独立 input/Select、跟随复选框、暂停和导出按钮 | 复用正式工具栏和输入组件；按能力配置筛选内容 |
| 列表 | `src/features/logcat/LogList.tsx`，表头、列宽、动态行高、跟随与查找条 | `src/features/ios/IosLogList.tsx`，独立虚拟化、固定行高及独立样式 | 抽取共同列表渲染与交互，平台仅提供展示投影和列定义 |
| 详情 | 可调整高度、原文复制、关闭、Android Tag 动作 | 单独详情块、无相同操作集 | 共用底部详情容器；平台专属动作按能力显示 |
| 快捷键 | 空格暂停、⌘/Ctrl+L 清空、⌘/Ctrl+E 导出；列表查找 | App 通用快捷键直接跳过 iOS | 路由到当前平台/当前 Tab，同键同义且输入时不误触 |
| Tab 状态 | `useLogTabs` | `useIosWorkspaceTabs`，独立持久化键 | 外观和通用动作一致，保留来源隔离与旧配置，不强行合并存储 |

两端使用相同虚拟化库并不代表复用了同一个列表组件；之前的 IOS3-060 验收证明 iOS 分支可用，没有证明双平台 UI 和交互一致。原有功能与真机证据保留，UI 对齐重新验收。

## 对齐边界

### 第二批实施约定（2026-11-12）

063 从现有 Android LogList 提取唯一 LogViewport，保留堆栈/分块上游处理、原数字 ID 定位与 Android 列宽存储键；iOS 使用中立投影与独立列宽键。查找匹配正文和可见的 Tag/进程/模块列，原始级别与 Unity 推断值各自展示、各自着色，不用推断覆盖原始级别。动态行高、单行超长折叠、滚动跟随/回到最新、查找索引与高亮均由同一组件提供；刷新后的查找结果不能按旧数组下标定位另一条记录。

064 抽取共用详情容器，保留 Android Tag 动作与旧高度偏好，iOS 独立高度偏好，复制始终使用 raw。正式 iOS 视图独立组装列表和详情，不再挂载 Probe 列表；Probe 保留旧诊断 UI。iOS Tab 增加独立 find 状态，查找查询/选项可保存，匹配位置、选中、快照不跨会话恢复。

正式页的空格/⌘或Ctrl+L/E 统一按当前平台/Tab 路由；列表的⌘或Ctrl+F 只由当前已挂载 viewport 处理。输入框、可编辑区域、弹窗、下拉菜单、Probe、设置和工具页不触发正式工作区动作；事件 defaultPrevented 时不重复处理。iOS 原文 TXT 导出使用同一选择器，完整会话 ZIP 的运行中禁用与归属校验保持原样。快捷键不改变用例引擎、采集控制器或原始落盘。

### 第一批实施约定（2026-11-10）

061/062 先引入中立展示投影/列能力（保留原始记录与 Android ID），由 iOS 视图过滤/计数使用；063 再接共享列表，不能因本批工具栏统一而宣布列表已统一。搜索匹配 iOS 原文（含进程/模块），普通文字不区分大小写，正则采用不区分大小写的 JavaScript RegExp；非法正则显示错误且返回空匹配，不悄悄退化成普通文字。

iOS Tab 在现有 `ios-workspace-tabs-v1` 增量保存 regex/activeFilterId，旧缓存缺失时默认 false/空。iOS 搜索历史、常用及命名筛选单独放在可选 `Prefs.iosLog` 字段，随原 version 2 配置导入/导出；旧 Android 字段、SavedFilter 和内置注册表不变，旧配置缺失该字段时按空集合处理，合并时本地优先、不同内容同 ID 重新编号。设置页过滤器区域提供 iOS 专属维护入口，正式日志页只应用/保存。

两端共用正式工具栏的操作组及搜索控件；iOS 不再在 IosLogList 中重复显示筛选/暂停/导出控件，Probe 保留原专用控件。动作路由保持当前 Tab 暂停快照、清空边界和 TXT 导出语义，快捷键完整对齐留给064。

- 共同列以时间、PID、级别、内容为基础。Android 保留 TID/Tag；iOS 使用进程、可选模块、Apple 原始级别和独立 Unity 推断信息。缺失字段显示“—”或隐藏，不把进程强塞 Tag、伪造 TID、把 notice 当 Unity Info。
- Apple 原始级别为独立筛选；Unity 推断级别与来源保留，不能通过统一颜色或字段覆盖原始信息。`<private>`、疑似乱码及截断标记照实展示。
- 搜索过滤与列表内查找分开：前者改变当前 Tab 可见结果，后者高亮、定位且不改变采集。共享匹配实现，明确搜索字段、正则错误、大小写与多行行为；支持文字搜索、正则及历史输入。仍只覆盖展示窗口/暂停快照，不承诺搜索全部落盘历史。
- 保存过滤器按平台区分：旧记录默认 Android；iOS 保存搜索及两类级别，不复用 Android 包名、PID 解析和 Tag 屏蔽语义。若涉及配置增量字段，兼容 version 2 导入导出、远程配置、恢复与旧字段。不能只展示同名按钮却触发 Android 行为。
- 平台列宽偏好独立存储，保留 Android 当前列宽；字号、主题与通用布局复用现有偏好。窗口尺寸/字号/列宽变化均重新测量行高，避免堆栈重叠或选中错位。
- 行身份不能只用数组下标或 iOS PID；iOS 以设备/会话/sequence 构造稳定标识。共享展示模型保留原始记录引用，Android 原有数字 ID 和定位规则继续兼容；禁止将 IosLogRecord 强转 LogEntry。
- 暂停仍仅固定当前 Tab 展示，底层持续采集；清空仅改变当前 Tab 展示边界；换设备/会话重置运行态，保留筛选偏好。保持现有 iOS 展示上限、计数、淘汰及落盘独立语义。
- 测试用例监测仍归 IOS3-080，本轮不新增 iOS 测试 Tab，也不改变规则树、作用域或缺失判定。隐藏不适用的 Android 工具、WiFi、Tag 动作属于合理能力差异。

## Probe 保留与会话协调

- Probe 可继续使用简化专用列表，不要求诊断页和正式页视觉一致；正式工作区不能依赖 Probe 的页面布局。
- 保留 App 根部唯一 iOS 会话 Hook 和现有后端控制器。进入/返回 Probe 不新增事件订阅或自动另起采集；设备、进程筛选及启动状态以共享采集状态为准。
- 正式页各 Tab 与 Probe 的展示选择/筛选不互相覆盖；采集启停会影响共享会话，应在两处反映同一事实，不伪装两份独立采集。
- 保留工具路径、设备/信任/锁定、通信诊断和接收/发送/丢弃等详细信息；正式页将长说明和诊断细节移入帮助/状态区域，落盘失败等关键错误仍持续可见。
- IOS3-100 的方向改为完善保留入口与说明，不再把删除 Probe 作为目标。是否对普通生产包开放，后续另行明确，不由本轮扩大入口范围。
